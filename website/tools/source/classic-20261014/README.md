# Source of the "Classic view" of the protocol archive

`styles-20261014.css` is the site stylesheet of the light design that was in production from 2026-10-14 to
2026-10-16, immediately before the current design. Provenance (verified 2026-11-18):

- byte-identical to git commit `6d9497c` (branch `site-redesign`) `website/styles-20261014.css`;
- byte-identical to the copy inside the production backup `/home/admin/backups/site-20261016-before-premium.tgz`;
- SHA-256 `6e45c90e3e4f5ac8e171bd4e02f1717b33cedfac814d35da684f5438e48d3ac7`.

The classic archive markup is generated by `build_release.py` from the current registry (same documents, counts and
links as the current view); only the presentation is restored. `tools/make_classic_css.py` turns this file into
`archive-classic-<date>.css`. Do not edit this source copy.

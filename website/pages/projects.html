Engineering the framework into reality

Overview

Dikenocracy is not only a theory. It is also an engineering and public-infrastructure effort expressed through concrete tools and experiments. Each project implements a bounded part of the protocol stack in verifiable, testable software.

Active projects

Tool

Converter DTI

A deterministic converter between Gregorian, Hebrew, and Dikenocratic Time Interface (DTI) formats. Implements DKP-0-TIME-001 with a canonical JDN-based domain layer, FastAPI service, and Streamlit client.

Tool

Shadoo

Encrypt and decrypt messages locally in your browser with a shared code phrase. Shadoo uses AES-256-GCM, detects tampering, and supports message expiry. Plaintext, code phrases and keys are not sent to the server. The website downloads its application files and checks for updates; encryption and decryption work while you are online.

Post-Nuclear Survival Manual

A comprehensive survival reference covering preparedness without a private bunker, the first sixty seconds, shelter, radiation units and dose-rate interpretation, fallout decay, decontamination, potassium iodide, water, food, sanitation, medical care, communication, and long-term recovery after a nuclear catastrophe. Published in English, with the Russian original alongside.

Ayalon Model

Real-time physical impact model for Highway 20 (Ayalon), Israel. Measures congestion cost in vehicle-hours, excess fuel, CO₂, and financial leakage using live TomTom traffic data, Gov.il fuel pricing, and air-quality feeds. Layer L5 — Transport.

Mazkira — Business Assistant

Secure assistant for small businesses in Israel: documents, bookkeeping support, taxes (VAT, income tax, Bituach Leumi estimates), CRM and financial analysis. Each account has its own isolated space; documents and sensitive fields are encrypted at rest. Interface in Hebrew, Russian and English. Not tax advice and not a certified bookkeeping system.

How it works

Every conversion passes through the Julian Day Number (JDN), a single authoritative time scalar. The DTI layer is a deterministic 360-day derived representation:

The count starts at the epoch anchor JDN 0, which is not itself a dated day. JDN 1 is Year 1, Day 1 (DY1-001); every DTI year has exactly 360 days numbered from 1:

DY = floor((JDN − 1) / 360) + 1 · DOY = ((JDN − 1) mod 360) + 1

This conversion is fully reversible: JDN = (DY − 1) × 360 + DOY. All operations are integer-only and machine-auditable. Days before the epoch are not defined.

This is the author's clarified convention (2026-11-18). The published text of DKP-0-TIME-001 (sections 5–6 and the test-vector table) still states an earlier zero-based form; a correction of that text awaits the author's approval and has not been published yet.

Hebrew dates are computed via a full calendar algorithm (Gauss/Reingold–Dershowitz) implemented entirely in client-side JavaScript — no server required.
